# 学习指南

## 打开项目

1. 将源码压缩包解压到一个文件夹。
2. 在 Qt Creator 中选择“文件 → 打开文件或项目”，打开 `CMakeLists.txt`。
3. 选择 Qt 6.8 或更新版本的桌面 Kit，确保已安装 Qt Multimedia 模块。
4. 配置项目后点击“构建”，再点击“运行”。本项目已使用 Qt 6.8.3 和 Visual Studio 2022 编译通过。

这是 CMake 工程，工程入口是 `CMakeLists.txt`。界面通过 C++ 代码创建，没有 `.ui` 文件；学习布局时请看 `buildUi()`。

## 文件与阅读顺序

| 文件 | 内容 |
| --- | --- |
| `CMakeLists.txt` | C++ 标准、源文件列表和 Qt 模块依赖 |
| `src/main.cpp` | 创建 QApplication、设置应用名称、显示窗口、进入事件循环 |
| `src/camerawindow.h` | 窗口类声明、界面控件和拍照状态 |
| `src/camerawindow.cpp` | 界面布局、信号连接、相机选择、定时拍照和保存处理 |

建议先读 `main.cpp`，再读头文件，最后按下面的功能流程阅读实现。

## 界面与信号

`buildUi()` 用 `QVBoxLayout`、`QHBoxLayout` 和 `QFormLayout` 排列控件。按钮使用 `QPushButton`，相机列表使用 `QComboBox`，间隔使用 `QDoubleSpinBox`。

构造函数中的 `connect()` 把事件连接到处理函数。例如，定时器发出 `timeout` 信号时调用 `onTimer()`；照片保存完成后，`imageSaved` 信号调用 `onImageSaved()`。按钮点击也是通过信号连接到成员函数的。

## 相机与拍照流程

`refreshCameras()` 枚举相机并更新下拉框，`selectCamera()` 创建和启动选中的 `QCamera`。`QMediaCaptureSession` 把相机、负责照片捕获的 `QImageCapture` 和显示预览的 `QVideoWidget` 连接起来。

自动拍照流程：

```text
点击开始 → startAuto()
         → 等待相机就绪 → startFirstPhotoIfReady()
         → takePhoto() 拍第一张，并启动定时器

定时器到期 → onTimer()
           → 检查相机是否就绪、上次照片是否仍在保存
           → takePhoto() 发出拍照请求
           → imageSaved 信号 → onImageSaved() 更新计数
```

`captureToFile()` 返回拍照请求编号，保存完成通常发生在之后。代码用 `pendingId_` 记录正在处理的请求：负数表示当前没有待完成请求。收到完成信号后，先核对编号，再更新计数。因此，“已保存”计数表示实际完成保存的照片数量。

`autoRunning_` 表示自动拍照是否开启；`waitingForFirstPhoto_` 表示是否还在等待拍第一张。`stopAuto()` 停止定时器，但已经发起的拍照仍会继续完成。

定时器使用毫秒，界面输入单位是秒，`intervalMilliseconds()` 负责转换。若上次照片仍在保存，到期的拍照会跳过，不会堆积请求。因此设定间隔是调度间隔，实际拍摄频率还取决于相机和保存速度。

## 保存与设置

`ensureOutputFolder()` 确保保存目录存在，`takePhoto()` 生成包含时间和序号的 JPEG 文件名。`chooseFolder()` 修改保存目录，`openFolder()` 打开该目录。`QSettings` 保存拍照间隔和目录，供下次启动恢复。

## 练习建议

1. 修改默认间隔和窗口文字，熟悉控件属性。
2. 增加“最多拍摄 N 张”的设置，达到数量后调用 `stopAuto()`。
3. 增加最近一张照片的缩略图，理解拍照请求与保存完成的区别。

真实相机功能尚未做硬件验证。自行运行后，可依次检查预览、手动拍照、自动拍照、调整间隔、停止，以及 JPEG 文件是否能正常打开。
