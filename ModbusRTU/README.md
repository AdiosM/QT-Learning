# 串口调试助手 (HelloQt)

一款基于 **Qt 6** 的多功能串口调试工具，集 **串口收发调试**、**自定义协议组帧/解析**、**Modbus RTU 主站调试** 与 **实时波形显示** 于一体。采用清晰的分层架构与事件驱动设计，可作为 Qt 串口通信、多线程、协议解析学习的完整示例工程。

---

## ✨ 功能特性

### 串口调试
- 自动枚举系统串口，关闭时重新检测，支持热插拔
- 可配置波特率（9600 ~ 115200），默认 8-N-1 无流控
- 接收区支持 **HEX / ASCII** 切换显示，带毫秒级时间戳
- 发送区支持 **HEX / 文本** 发送（如 `AA 01 FF`）
- 收发字节计数与一键清零
- 设备被强拔（ResourceError）时自动关闭串口并复位 UI，避免"僵尸状态"

### 自定义协议
- 组帧格式：`AA 55 + 长度 + 载荷 + 校验和`
- 解析器自动处理 **粘包 / 半包**，校验和验证
- 缓冲区溢出保护（>64KB 自动清空），丢弃无效数据并提示（syncLost）
- **自动应答** 规则演示：收到载荷 `01` 自动回复 `02`
- 载荷前 2 字节按大端序解析为温度值（单位 0.1°C）并绘制波形

### Modbus RTU 主站
- 基于 Qt SerialBus 模块（`QModbusRtuSerialClient`）
- 支持 **FC03** 读保持寄存器、**FC06** 写单个寄存器
- 异步请求/响应模型（QModbusReply + finished 信号），超时 1s、失败自动重试 3 次
- **自动轮询**（500ms 周期读取）开关
- 寄存器值自动换算（raw / 10.0）并绘制红色波形曲线

### 实时波形
- 基于 QCustomPlot 的双曲线实时滚动波形
  - 蓝色：自定义协议温度 / 未连接时的模拟正弦波
  - 红色：Modbus 寄存器数值
- 滑动时间窗口（最近 10s）、Y 轴自适应缩放、图例显示
- Modbus 连接成功后自动停止模拟数据源，断开后恢复

## 🏗 架构设计

项目采用 **四层架构**，各层职责单一、互不越权：

```
┌──────────────────────────────────────────────────────┐
│  UI 层  MainWindow                                    │
│  串口配置区 / 接收区 / 发送区 / Modbus 调试区 / 波形区   │
└───────┬───────────────┬────────────────┬─────────────┘
        │ 命令+事件      │ 喂入字节流      │ 读写+事件
┌───────▼───────┐ ┌─────▼───────┐ ┌──────▼────────┐
│ SerialPort    │ │ Protocol    │ │ Modbus        │
│ Manager       │ │ Parser      │ │ Manager       │
│ (工作线程)     │ │ (UI 线程)    │ │ (UI 线程)      │
└───────┬───────┘ └─────────────┘ └──────┬────────┘
        │                                │
┌───────▼───────┐              ┌─────────▼────────┐
│ QSerialPort   │              │ QModbusRtuSerial │
│               │              │ Client           │
└───────────────┘              └──────────────────┘
```

### 线程模型

```
UI 线程                                工作线程
├─ MainWindow                         └─ SerialPortManager
├─ ProtocolParser                          └─ QSerialPort
├─ ModbusManager
├─ QTimer (模拟数据 / Modbus 轮询)
└─ QCustomPlot

跨线程通信：MainWindow::requestSendData ──Qt::QueuedConnection──▶ SerialPortManager::sendData
```

- **UI 层绝不直接触碰 `QSerialPort`**：只通过 `SerialConfig` / `PortInfo` 结构体下发命令、订阅事件信号
- 串口收发运行在独立工作线程，避免阻塞界面；线程结束时 `deleteLater` 自动销毁 manager
- 析构时 `quit() + wait(3s)`，超时 `terminate()` 兜底，防止死锁
- UI 层维护本地状态 `m_isPortOpen`，避免跨线程读取工作线程对象

## 📜 协议定义

### 自定义帧格式

| 偏移 | 长度 | 内容 | 说明 |
|------|------|--------|------|
| 0 | 1 | `0xAA` | 帧头 1 |
| 1 | 1 | `0x55` | 帧头 2 |
| 2 | 1 | N | 载荷长度 |
| 3 | N | payload | 载荷数据 |
| 3+N | 1 | checksum | 除校验外全部字节累加和（mod 256） |

**示例**：载荷 `01 F4` → 完整帧 `AA 55 02 01 F4 F6`
**温度解析**：载荷前 2 字节大端序，`01 F4` = 500 → **50.0 °C**

### Modbus RTU

| 功能码 | 操作 | 参数范围 |
|--------|------|----------|
| 03 | 读保持寄存器 | 地址 0~65535，数量 1~125 |
| 06 | 写单个寄存器 | 地址 0~65535，值 0~65535 |

- 从站地址：UI 已预留配置控件（当前通信实现固定为 1，便于扩展多从站总线）
- 超时 1000ms，重试 3 次
- 显示值 = 原始值 / 10.0

## 🚀 快速开始

### 环境要求
- Qt 6.5 或以上（含 SerialPort、SerialBus、PrintSupport 模块）
- CMake 3.19 或以上
- 支持平台：Windows / Linux / macOS

### 构建

```bash
# 1. 配置（如 Qt 不在默认路径，指定 CMAKE_PREFIX_PATH）
cmake -B build -S . -DCMAKE_PREFIX_PATH=/path/to/Qt/6.8.3/mingw_64

# 2. 编译
cmake --build build --config Release

# 3. 运行
./build/HelloQt             # Linux/macOS
build\Release\HelloQt.exe   # Windows
```

或直接使用 **Qt Creator** 打开 `CMakeLists.txt` 构建运行。

## 📖 使用指南

### 1. 串口调试
1. 选择串口与波特率，点击 **打开串口**
2. 勾选 **HEX 显示** 查看十六进制数据；勾选 **协议解析** 启用帧解析模式
3. 发送区输入文本或 HEX，勾选 **协议组帧** 可自动套上 `AA 55` 帧头与校验和
4. 勾选 **自动应答** 后，收到载荷 `01` 会自动组帧回复 `02`

### 2. Modbus 调试
1. 点击 **连接 Modbus**（会自动关闭普通串口，二者互斥占用同一物理端口）
2. 设置起始地址、寄存器数量/值
3. 点击 **读 / 写** 发起单次请求；勾选 **自动轮询(500ms)** 周期读取
4. 结果区显示 `0xXXXX (浮点值)`，红色曲线同步刷新

### 3. 波形区
- 未连接设备时显示 **模拟正弦波 + 噪声**，保持界面动态效果
- 自定义协议收到温度帧 → 蓝色曲线更新
- Modbus 连接成功后自动停止模拟数据，轮询数据驱动红色曲线

## 💡 设计亮点

1. **事件驱动 + 命令接口分离**：所有异步操作"下发命令 → 信号反馈结果"（如 `openPort → portOpened`），UI 与底层完全解耦
2. **跨线程安全加固**：对工作线程对象的一切调用均通过信号 + `Qt::QueuedConnection` 投递，数据自动拷贝，杜绝竞态
3. **粘包/半包教科书式处理**：缓冲区攒包 + 帧头对齐 + 长度预判 + 循环取帧；校验失败的帧直接消费丢弃，不污染后续数据
4. **内存/资源保护**：协议缓冲区超 64KB 自动清空防内存涨爆；设备被强拔（`ResourceError`）时主动关串口，避免对象进入"僵尸状态"
5. **异步 Modbus 模型**：`QModbusReply` 的 `finished` 信号驱动结果回调，`deleteLater` 保证回复对象生命周期安全
6. **互斥资源管理**：普通串口与 Modbus 连接互斥，切换时自动释放对方占用的物理端口
7. **编译依赖隔离**：头文件大量使用前置声明（如 `class QCustomPlot;`），真实 include 下沉到 `.cpp`，显著加快增量编译

## ❓ 常见问题

| 问题 | 排查建议 |
|------|----------|
| 串口打开失败 | 检查是否被其他串口工具占用；设备是否连接；驱动是否安装 |
| Modbus 连接失败 | 确认从站地址/波特率匹配；Modbus 与普通串口互斥，连接前会自动关闭普通串口 |
| 接收区无数据 | 确认勾选的显示模式（HEX/协议解析）与设备输出格式一致 |
| 波形图看不到曲线 | 检查数值是否超出 Y 轴范围（Y 轴为双曲线自适应） |
| 设备拔出后界面无响应 | 程序已自动处理：`ResourceError` 触发自动关闭并复位 UI |
| 编译报 deprecated 警告 | 来自 QCustomPlot 与 Qt 6 的版本代沟，属 Warning 不影响运行 |
